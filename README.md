# FITTED — hosted demo

Live: **https://majieddd.github.io/fitted/**

Static build of the FITTED app (source: private repo `majieddd/fitted-app`).
The full composition, verification, and sizing pipeline runs client-side, so
the demo works with no server — open it on a phone, tablet, or desktop.

Rebuild with `./scripts/build-static.sh` in the source repo.
